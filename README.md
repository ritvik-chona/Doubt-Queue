# Doubt Queue

A course doubt queue: students post doubts in courses they've joined, peers upvote, and TAs claim and resolve them. Similar existing doubts are suggested while a student types, to cut down on duplicates.

Full setup, architecture notes and deployment details will be added as the project is built.

## Structure

- `server/` - Node + Express + Mongoose API
- `client/` - React + Vite frontend
